# Niebo nad nami - silnik LPE

Silnik komponentu interaktywnego `aplikacje_obszar_7._lpe/niebo_nad_nami`. Pliki w tym katalogu są wynikiem polecenia `npm run build` z repozytorium źródłowego.

Punkty wejścia są modułami AMD zgodnymi składniowo z ECMAScript 5. Komponent implementuje cykl życia LPE, zapis i zamrożenie stanu, edytor instancji, tryby kontrastu, wydruk oraz lokalne zasoby WebGL/Canvas.
